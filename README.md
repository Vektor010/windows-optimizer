## 🚀 Быстрый старт

1. Скачайте свежий релиз **`NOVA_Optimizer_v2.1.zip`** из [Releases](https://github.com/Vektor010/windows-optimizer/releases/latest).
2. Распакуйте архив в любую удобную папку.
3. Нажмите **правой кнопкой мыши** на `NOVA.ps1` ➔ **Выполнить с помощью PowerShell**.
4. Скрипт сам запросит права Администратора и запустит меню.

## ✨ Ключевые особенности (NOVA 3.0)

- 🤖 **Тотальное Удаление ИИ (AI Debloat):** Полностью вырезает Windows Copilot (включая скрытие иконки с панели задач) и блокирует функционал Recall на уровне ядра.
- ⚡ **Мгновенный интерфейс (WMI Caching):** NOVA Console кэширует оборудование при старте. Перемещение по меню происходит за **0 миллисекунд**.
- 🖱️ **Modern Fluent Cursor:** Встроенный скрипт автоматически скачивает с GitHub и активирует тёмный сглаженный курсор Windows 11 (1:1 Pixel Mapping, без акселерации).
- 🧹 **Nuclear Debloat:** Агрессивная зачистка телеметрии, очистка всех кэшей DirectX/NVIDIA, логов и временных файлов в один клик.
- 🧮 **Убийца UWP:** Возврат к классическому Блокноту, Калькулятору и Просмотру Фотографий без мусорных Modern-приложений.

## 🛡️ Безопасность и Откат

NOVA Optimizer гарантирует 100% безопасное применение твиков. Перед запуском **любого** твика вы можете нажать **`[B]`**, чтобы создать снимок текущего состояния реестра и служб. 
Если что-то пойдет не так, нажмите **`[D]`**, и система вернется к исходному состоянию за 5 секунд.
